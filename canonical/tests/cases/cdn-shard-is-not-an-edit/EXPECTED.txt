【封面换了 CDN 分片不是编辑，换了图才是】
两个作品，两份档案。作品 701 的封面只有主机变了（img1 → img3），路径一模一样
——同一张图；作品 702 的封面**图片 id 变了**（p702a → p702b），那是真的换了封面。
实测：豆瓣某个时点会把图挪一次分片（436197 条路径里，同一份档案内主机不一致的
0 条；589 张海报各只挪过一次、没有一张挪回去），而这在全量真实档案上凭空造出
**111 条作品修订**。
**两个方向都钉。** 只钉「不许多」的话，把 cover_url 从 fields 里整个删掉也是
绿的，而那是真的丢数据；只钉「不许少」的话，规则删掉也是绿的。
解析器必须：2 个作品、3 条作品修订（701 一条，702 两条）。
